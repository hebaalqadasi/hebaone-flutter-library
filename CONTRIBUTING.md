# Contributing

## Branches

Use the following branch prefixes:

- feature/
- fix/
- refactor/
- docs/
- test/
- chore/

## Commits

Use Conventional Commits.

Examples:

feat: add custom button
fix: resolve button overflow
docs: update component documentation
refactor: simplify button implementation

## Components

Every reusable component should include:

- Source code
- Documentation
- Preview
- Example when needed
- Tests when appropriate
